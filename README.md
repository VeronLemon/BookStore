# BookStore

Напишите классы для предметной области книжного магазина.

Структура проекта:
- main — запуск программы.
- application — основная логика работы книжного магазина.
- domain — класс книги и интерфейс репозитория.
- infrastructure — работа с JSON-файлом.
- presentation — консоль.
- tests — проверка работы.
